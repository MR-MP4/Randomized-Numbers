# Charity: Water — Community Water & Sanitation Simulator

A React + TypeScript simulation game inspired by Charity: Water's mission. Manage your community budget and resources, construct clean water pumps and sanitation facilities, run outreach campaigns, and advance through days to improve local sanitation, agriculture, and education.

## Features

- **Resource & Budget Management**: Track your budget and spend strategically on infrastructure or fundraising campaigns.
- **Infrastructure Building**:
  - **Water Pump**: $40 cost · boosts Sanitation (+2) and Agriculture (+2).
  - **Sanitation Station**: $30 cost · boosts Sanitation (+3).
- **Outreach & Learning**:
  - **Advertise**: $15 cost · yields $30 (+$15 net gain) to keep the project funded.
  - **Educate**: $20 cost · boosts community Education (+2).
- **Day Progression**: Advance the calendar to monitor daily operations and plan next steps.
- **Interactive Navigation**: Quick-jump navigation across builds, sanitation, agriculture, and education sections.
- **Faithful Aesthetic**: Preserves the original game shell layout, CSS-based illustration art, and Charity: Water credentials sidebar.

## Tech Stack

- React 19
- TypeScript
- Vite
